# Niofia Images

Product image CDN for Alibaba International listings.

## Folder structure

One folder per product, kebab-case:

- `car-seatbelt/raw/` + `car-seatbelt/generated/`
- `dog-lifejacket/raw/` + `dog-lifejacket/generated/`

## Naming

- `01-main-white.jpg` main image 1
- `02-scene.jpg` main image 2
- `03-features.jpg` main image 3
- `04-lifestyle.jpg` main image 4
- `05-details.jpg` main image 5
- `06-size-chart.jpg` main image 6
- `07-how-to-use.jpg` detail image
- `08-colors.jpg` SKU colors
- `09-multi-angle.jpg` multi angle
- `10-comparison.jpg` comparison
- `11-brand.jpg` brand guarantee
